# zeus/ingest/ — Iris

Walks data sources, routes chunks to the memory or knowledge layer per declared target. Root brief: [`../../CLAUDE.md`](../../CLAUDE.md). User-facing guide: [`../docs/ingest-guide.md`](../docs/ingest-guide.md). Paths and symlinks: [`../docs/ingest-paths.md`](../docs/ingest-paths.md).

## Layout

| File | Role |
|------|------|
| `pipeline.py` | `run_ingest(source, ...)` orchestrator; retries, privacy classifier, per-chunk routing |
| `run.py` | CLI entry (`python -m zeus.ingest.run`); parses `--source`, `--target`, `--config`, `--dry-run` |
| `config.py` | Pydantic loader for `config.yaml`; env-var interpolation |
| `config.yaml` | Declarative per-source routing, paths, excludes |
| `scheduler.py` | APScheduler hooks for periodic ingest runs |
| `types.py` | `Chunk`, `chunk_text`, `IngestResult` |
| `sources/*.py` | One module per source (markdown, obsidian, chatgpt, email, newsletter, bookmarks, git, gcal, context_pack) |

## Invariants

- **Every `IngestSource` subclass declares `target: Literal["memory", "knowledge", "reference"]` as a class-level attribute.** Default is `memory` for safety; most bulk sources override to `knowledge`. `reference` is accepted in config but rejected by the pipeline (query-time only).
- **`Chunk.source` plus a pipeline-derived `source_id` are the dedupe key.** The `Chunk` dataclass carries `text`, `source`, `metadata`, `user_id`. `source_id` is generated by the pipeline from the source label so `MemoryStore.delete_by_source(source, source_id)` and `KnowledgeStore.delete_by_source(source, source_id)` can wipe a re-ingest cleanly.
- **Memory-layer writes call `small_llm_call(response_format=FactExtraction, min_privacy_tier=1)`.** Knowledge-layer writes skip the LLM entirely.
- **Transient errors retry with exponential backoff** inside `run_ingest`. See `_is_transient_ingest_error()` in `pipeline.py` for the classifier.
- **Privacy classifier** tags every chunk with a tier before storage; PII-bearing content is routed away from tier-2 providers in `small_llm_call`.

## Env flags

| Env | Default | Purpose |
|-----|---------|---------|
| `IRIS_INGEST_PROMPT_ON_TRANSIENT` | `auto` | `auto` / `always` / `never` retry prompting |
| `IRIS_INGEST_TRANSIENT_MAX_RETRIES` | `0` (unlimited) | Cap retries per chunk |
| `IRIS_INGEST_PRIVACY_TIER` | (derived) | Override privacy tier for a run |
| `OBSIDIAN_VAULT_PATH` | (unset) | Vault root for `obsidian` source |
| `CHATGPT_EXPORT_PATH` | `zeus/data/raw/chat-history` | ChatGPT export root |
| `NEWSLETTER_IMAP_HOST` / `_USER` / `_PASS` / `_PORT` | Gmail defaults | Newsletter IMAP |
| `NEWSLETTER_SOURCES` | (JSON) | `{type: email, ...}` mapping |
| `OLLAMA_EMBED_TIMEOUT_SEC` | `120` | Per-chunk embed timeout |
| `ZEUS_INGEST_CHUNK_SIZE` | `512` | Default chunk size (tokens) |
| `ZEUS_INGEST_CHUNK_OVERLAP` | `72` | Default overlap |

## Running

```bash
# Curated profile sources (memory layer, LLM fact extraction)
python -m zeus.ingest.run --target memory

# Bulk sources (knowledge layer, no LLM on the write path)
python -m zeus.ingest.run --target knowledge

# Single source, dry run
python -m zeus.ingest.run --source obsidian --dry-run

# Custom config
python -m zeus.ingest.run --config path/to/alt.yaml
```

Routing comes from `config.yaml` + the per-source `target` attr. CLI flags override per-invocation.

## Adding a source

```python
# zeus/ingest/sources/<name>.py
from typing import AsyncIterator
from zeus.ingest.types import Chunk, chunk_text

class <Name>Source:
    target = "knowledge"   # or "memory"

    def __init__(self, ..., chunk_size=512, chunk_overlap=64, user_id="chris"):
        ...

    async def chunks(self) -> AsyncIterator[Chunk]:
        for item in self._load():
            for text in chunk_text(item.text, self.chunk_size, self.chunk_overlap):
                yield Chunk(
                    text=text,
                    source=f"<name>:{item.id}",   # used as the dedupe key prefix
                    metadata={...},
                    user_id=self.user_id,
                )
```

Then:

1. Register in `run.py:build_sources()`.
2. Add a block in `config.yaml` with `target:` and any per-source config.
3. If it lists in a Ruflo agent manifest, add to `zeus/orchestration/agents/iris.yaml:config.sources`.

## What not to do

- Don't call `small_llm_call` on a knowledge-layer source. That defeats the separation.
- Don't return chunks with floating `created_at`. Use ISO-8601 strings. The stores will reject floats.
- Don't parse `.docx`, PDF images, or OCR'd content into the memory layer. LLM extraction on garbled text hallucinates (real bug: CJK glyph hallucination from qwen2.5 on OCR noise).
- Don't bypass `delete_by_source` on re-ingest. Duplicates in Qdrant are hard to clean up.
- Don't commit anything under `zeus/data/raw/` (gitignored) to the repo.
