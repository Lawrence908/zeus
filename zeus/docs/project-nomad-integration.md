# Project N.O.M.A.D. and Zeus

How Zeus connects to a local [Project N.O.M.A.D.](https://github.com/Crosstalk-Solutions/project-nomad) install. This doc is the working checklist; extend it as you discover APIs and paths.

## Install location (this machine)

- **Source / build tree:** `/home/chris/apps/project-nomad`
- **Command Center (typical):** browser at `http://127.0.0.1:8080` or `http://<host-ip>:8080` (see upstream install notes).

## What N.O.M.A.D. provides

N.O.M.A.D. orchestrates Dockerized tools: local AI (Ollama + Qdrant RAG), Kiwix, Kolibri, offline maps, CyberChef, FlatNotes, benchmarks, and more. Upstream describes it as offline-first with **no built-in authentication**; treat exposure as a **local-network** concern and do not put the Command Center on the public internet without a separate auth layer.

## Zeus integration strategy (hybrid)

| Need | Approach |
|------|----------|
| Fresh operational data (what is installed, health, collection lists) | **Live HTTP** from the Command Center API once routes are mapped |
| Searchable context inside Zeus chat / Oracle | **Iris ingest** into mnemosyne (text catalogs, summaries, exported notes) |
| Huge binary corpora (e.g. full Wikipedia ZIMs) | **Not** ingested into Zeus by default; store **metadata** in Zeus if useful |

N.O.M.A.D.’s Ollama/Qdrant stack is **separate** from Zeus’s mem0 + Qdrant. Duplicating entire knowledge bases into Zeus is optional and expensive; default is awareness + metadata.

## Phase 1 — Ingest without custom code

Mirror text or small exports into `zeus/data/raw/nomad/` (or a symlinked subtree) and run:

```bash
python3 -m zeus.ingest.run --source markdown \
  --glob "nomad/**/*.md" \
  --base-dir zeus/data/raw \
  --dry-run
```

Adjust the glob to match your layout. Remove `--dry-run` when satisfied.

## Phase 2 — Live API in Zeus (planned)

After Phase 0:

- **Oracle:** proxy routes such as `GET /integrations/nomad/status` with short timeouts and bounded JSON.
- **MCP:** tools like `nomad_status` / `nomad_search` (see [mcp-server-spec.md](mcp-server-spec.md)).

## Phase 3 — Optional `NomadSource`

If you prefer a single snapshot file (JSON/MD) generated by a script against NOMAD, add an Iris source that reads that file and tags chunks with `integration: nomad` metadata. Register in `zeus/ingest/run.py` when implemented.
